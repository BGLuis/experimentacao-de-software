# Planejamento — Lab01S01

## Objetivo

Disponibilizar uma consulta GraphQL automática que reúna as métricas das RQs 01 a 06 para 100 repositórios populares.

## Divisão sugerida

| Responsável | Escopo |
| --- | --- |
| Integrante A | RQ01: idade; RQ02: pull requests aceitas |
| Integrante B | RQ03: releases; RQ04: última atualização |
| Integrante C | RQ05: linguagem primária; RQ06: razão de issues fechadas |

Cada integrante deve ter uma Issue própria, validar sua parte numa amostra de 5 a 10 repositórios e referenciar o número da Issue nos commits.

## Critérios de encerramento

- Consulta executa com token armazenado fora do Git.
- Retorna e exporta 100 repositórios com todas as métricas necessárias.
- GitHub Projects possui Backlog, To Do, Doing, Review e Done.
- WIP de Doing: máximo de 3 tarefas, uma por integrante.
- Issues e status do board refletem o andamento real do trabalho.
