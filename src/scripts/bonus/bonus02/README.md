# Bonus 02: O Fenômeno da Inteligência Artificial

Estes scripts investigam:
1. O crescimento vertiginoso de repositórios de Inteligência Artificial desde 2022.
2. A dominância massiva do Python nesses repositórios (mais de 6.8 milhões de estrelas).
3. A hipótese do Markdown: o crescimento recente de repositórios baseados primariamente em Markdown para uso como "Agent Skills" (instruções para LLMs) ou curadorias de IA.
