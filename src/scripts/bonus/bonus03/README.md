# Bonus 03: Dinheiro, Ideologia e Licenças

Este script (`analise.py`) cruza os aspectos legais com engajamento para investigar:
1. Como licenças restritivas e Copyleft (como AGPL v3) dependem muito mais de doações do que licenças permissivas (MIT).
2. O domínio da licença MIT e Apache 2.0 no ecossistema de Inteligência Artificial para facilitar adoção corporativa.
3. A relação entre a escolha da licença e a taxa de abandono e aceitação de Pull Requests.
