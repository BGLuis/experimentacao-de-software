# Bonus 04: Tendências de Tags e Engajamento

Este script (`analise.py`) mapeia:
1. Matriz de Correlação cruzando diversas características quantitativas e desmistifica o mito de que "muitos commits trazem estrelas" ou que "código maior significa projeto melhor".
2. As combinações mais lucrativas de Linguagem + Tag em termos de média de estrelas, revelando o poder de repositórios educacionais, listas de "awesome" e ferramentas para desenvolvimento web/entrevistas.
