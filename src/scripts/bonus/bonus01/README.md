# Bonus 01: Análise Estrutural (O Paradoxo da Wiki e Tamanho do Código)

Este script (`analise.py`) investiga:
1. O impacto de possuir uma Wiki nativa do GitHub no sucesso do projeto (projetos maiores costumam usar documentação externa).
2. A relação entre o tamanho do repositório em KB e a taxa de abandono (projetos maiores tendem a ser menos abandonados).
3. Repositórios populares que desativam as issues.
4. O mito de que forks podem ser mais populares que os projetos originais.
